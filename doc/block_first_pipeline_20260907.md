# 街区先行、核心建筑按需处理（2026-09-07）

入口：`generate_model.py --urban-organization block-first --surface-road-style negative-space-v1`。
本次 PNG 使用 `--draft --review-only --png --review-png`，结束于 S7。

## 实际执行与边界

1. S1/S2 读取缓存、投影与统计源数据。当前仍读取全城建筑 GeoJSON；尚未实现空间数据库按需读取。
   植被实体默认关闭，但植被源数据仍用于场景测量与公园/湿地保护。
2. S3 路河拓扑先形成 city_blocks，保留道路 seam_graph。block-first 跳过按建筑形状退让/合并街区，
   仅对带 Wikidata/Wikipedia 或明确地标语义标签的候选提取地标，不对无名普通楼提取详细形状。
   现有旧 block_base 仍作为 S4 测量输入生成；最终载体由 S6 替换。
3. S4 保留城市/地貌测量。
4. S5 使用向量化建筑质心统计街区占用；从含语义地标的街区中按地标批准高度选核心，
   生成 `scene_policy.block_first`。记录完整源数量、占用街区、核心街区、源行号、预算、街区指纹和耗时。
5. S6 普通占用街区直接成面，扣除开放空间、水面及地标；仅核心街区调用现有 C 聚合与轮廓简化。
   建筑只在所属街区内聚合；无法生成核心块时回落到街区载体。
   道路拓扑尚未充分切细的大街区，使用 S5 建筑质心占用网格限制填充范围，避免整块丢掉城区。
   最终负空间街缝仍由统一 `finalize_city_surfaces` 布尔裁切。
6. S7 使用同一平面 PNG 渲染器。仅 PNG 请求跳过三维地形贴合分片；报告记录
   `geometry_scope=planar_review_only; terrain_contact_and_slicing_pending`。
   完整三维请求仍执行原严格贴合检查，未修复的非流形错误仍会阻断三维输出。

## 第一版可审阅策略

参数集中在 `aesthetic/block_first.py:BlockFirstPolicy`，没有城市名特例：

- 最多 32 个核心街区，每个最多 256 个建筑源要素；普通楼无需做全城轮廓聚合。
- 超过 500,000 m² 的街区只保留占用网格支持部分，防止道路未闭合导致整片白板。
  网格宽度为一个喷嘴折算到真实世界的距离，仅闭合一个网格间隔；它表示区域占用，并非建筑复制。
- 普通街区保留至少一个建筑质心的占用证据；此版本不凭空填充无建筑证据的郊野。
- 核心普通块高度两层，地标沿用已有真实高度/角色映射与地形约束。
- 数值属于可调性能/防误填预算，不是从参考 demo 得到的审美定律。

## 完整街道分割修订（2026-09-07）

v2 的街区构建使用 structural 网络，但 S6 的最终挖缝使用更稀疏的 seam_graph。
邻接街区虽已分开，渲染时因缺少实际负空间又连成大片。
block-first 现在在 S3 从原始道路选出完整城市街道，同一份几何同时供给
街区 polygonize、冻结 seam_graph 和最终布尔挖缝；不再应用显著性预算、
喷嘴尺度等级筛选或短线/无名过滤。旧组织路线不受此分支改变。

保留机动车各等级、residential、unclassified、living_street、pedestrian；
仅去除几何完全相同（含反向）的重复线。service、footway、path 等不在本轮
城市街道集合内；平行车道不擅自合并。主路强调与完整街道拓扑分离。
预处理缓存版本增加 complete-streets-v1，避免复用旧稀疏网络。

道路专项工具：`tools/diagnose_block_partition_rois.py`。
固定巴黎三个 3 km 局部，保持整幅约 25 km / 196 mm 的真实模型比例；
普通街缝 0.28 mm，主干 0.42 mm。以同一整块载体比较 tier-2 主骨架和完整街道：

| 区域 | 主骨架切后连通块 | 完整街道切后连通块 | 完整街道裁切时间 |
|---|---:|---:|---:|
| 中心 | 139 | 925 | 0.74 秒 |
| 东北 | 75 | 412 | 0.43 秒 |
| 西南 | 99 | 554 | 0.54 秒 |

全部读取、投影和制图耗时 23.0 秒。输出位于
`output/paris_complete_streets_3km_20260907/`。
这是无建筑、无水体的道路平面专项对照，不是旧成品像素对照，也不证明可打印性。
视觉上大块明显拆细，但密集街区在当前缝宽下仍偏粗，需整图审阅。

## 保留路网的缝宽与边缘实验

工具 `tools/experiment_complete_street_finish.py`，边缘函数
`aesthetic/block_edge_experiment.py`（仅实验调用，不改生产默认）。
同一巴黎三个 3 km 窗口，保留 25 km 成品的 scale=0.007762010308 mm/m，
每个窗口四个候选共享完全相同的道路几何指纹，不删短路、不改变路网等级。
额外 100 m 工作边界避免窗口边缘干扰切角。

| 候选 | 普通/主干缝宽 mm | 边缘 |
|---|---|---|
| A | 0.28 / 0.42 | 原形 |
| B | 0.20 / 0.30 | 原形 |
| C | 0.14 / 0.21 | 原形 |
| D | 0.20 / 0.30 | 约 0.04 mm 向内微切角 |

切角采用腐蚀后 bevel 回补并与原面求交，不向街缝扩张；几何摘要确定
0.75–1.25 倍微变化。分裂、消失、孔数量变化或单块损失超过 2% 时回退。
这不是沿边界添加高频噪声，也尚未处理外围占用网格方齿。
5 项新增测试通过：可重复性、零越界、块数量、小块保护、孔洞、禁用和参数验证。

最终对照位于 `output/paris_complete_street_finish_20260907_v3/`，本机热缓存
32.83 秒。三窗口 A/B/C/D 白色载体覆盖分别为
42.8/55.6/67.2/55.4%、58.7/68.3/76.4/68.2%、51.6/62.7/72.2/62.5%。
D 的切角前后块数分别保持 1060、452、638，越界新增面积均为 0。
全图观感切角变化很轻，主要收益来自收窄缝宽。

**验收边界**：仅路网切实心载体专项，不含真实城市建筑、公园、水体；不是完整成品。
B/C 有局部非单调裁切面积（收窄后部分位置反而损失，原始值 3.12–183.63 m²），
超过单输出像素面积的候选已在 evidence 中标记 `monotonic_area_gate=false`。
原因尚未确认，不按浮点噪声忽略；v1/v2 是遇到该检查而终止的诊断目录，保留不覆盖。
PNG 可用于审美选择，但正式默认值、3MF 和切片验收均未更新。
按 map-model-review 协议读图：B 比 A 平衡、C 更轻细，D 与 B 的整体差别有限；
需要人工选风格，几何异常需单独排查后再进入生产。
