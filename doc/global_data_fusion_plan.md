## 目标与边界

海外方案的目标不是把多个来源直接堆进模型，而是用交叉证据识别城市主结构、
补充真实缺失并减少 OSM 单源噪声。

必须保持这些边界：

- 多数据源只提供身份、显著性、连续性和缺失候选证据；底层网格、全局 Z、
  布尔运算和可打印性仍由确定性代码控制。
- 第一阶段不直接用外部参考几何替换 OSM。候选线必须通过距离、方向、双端
  连续性、道路等级和禁穿水体等检查，才能进入补线层。
- 不用“命令无报错”作为成功。道路、水体和建筑的输入数、保留数、补充数、
  拒绝数以及零要素原因必须写入诊断结果。
- 快速预览和正式 3MF 使用同一份已解析的构图/选择决策；正式模型另加水密、
  喷嘴宽度、层高和验证器约束，不能展示一套、打印另一套。

## 数据源分工

### 道路

1. **Overture Transportation**：主骨架和跨来源整合后的道路等级证据。
2. **OSM**：可打印的详细几何、名称、道路属性和城市纹理主来源。
3. **Microsoft Road Detections**：只生成漏路/断路候选，绝不无条件并入。

决策顺序：先用 Overture 给 OSM 道路打 `primary / secondary / context` 角色，
再对 OSM 中双端断裂或明显缺失的走廊查询 Microsoft 候选。只有通过拓扑和
几何门禁的短缺口才可补入。

### 水体

1. **OSM / Overture Water**：名称、类别和矢量边界。
2. **JRC Global Surface Water**：大水面、海岸和长期水面覆盖 mask。
3. **HydroRIVERS / HydroLAKES**：流域层级、河湖主次和规模证据。

JRC 分析必须使用可计算的原始栅格，不把展示用 RGB 瓦片当作真值。水体边界
仍需矢量来源；JRC 只约束“这里是否应当是稳定水面”，Hydro 数据只帮助判断
主次，避免海面/大湖被渲染成灰底或细线。

### 建筑

1. **OSM**：首选建筑轮廓和语义。
2. **Overture Buildings**：名称、高度和缺失覆盖候选。
3. **Microsoft Global ML Buildings**：仅在实测有边际增益的网格补缺。

Overture 已吸收部分 Microsoft 建筑数据，因此必须做来源/空间去重；不得因
重复来源把一个建筑叠加两次。高度要经过可信度、单位和异常值门禁，最终 Z
拉伸仍受打印层高与城市地标策略约束。

### 高程

继续使用项目已有 **SRTM DEM**，不在本方案中更换地形基线。

## 接入架构

第一阶段实现统一的 `VisualEvidenceGuide`，复用现有
`road_support(geometry)` / `water_support(geometry)` 接口：

```text
STAC/区域索引
    -> 有界 bbox 抽取与本地缓存
    -> 坐标统一、来源去重、有效性检查
    -> 道路三档 mask + 水体 mask + 来源证据
    -> 现有 road_roles / water_roles
    -> CompositionSpec/诊断 JSON
    -> PNG 与 3MF 共用选择结果
```

CLI 计划新增 `--global-evidence off|cache|network`，默认 `off`：

- `off`：完全不访问海外源。
- `cache`：只用已验证缓存；缓存缺失时明确降级，不联网。
- `network`：显式允许按 bbox 下载，必须同时设置单任务字节上限和超时。

国内 `--amap-salience` 与海外 `--global-evidence` 不能在同一任务中静默混用。
CompositionSpec 必须记录 provider、数据版本、缓存命中、bbox、要素数量、降级
原因和策略版本，不能把 Overture 证据误写成高德证据。

## 存储与流量策略

- 大型原始区域包落在 `cloud-data` 或 Windows 的大容量数据盘，不放 `cloud-api`。
- 原始数据按 release/source 保存一次；worker 只获取按 bbox 裁剪后的城市包。
- 缓存键至少包含 `source + release + bbox + schema/policy version`，不同用户提交
  相同区域时共享数据缓存，但任务、权限和成品归属仍隔离。
- 下载前先读取 Content-Length/索引行数并给出预算；超过预算时不启动。
- 试点先限定一个 5 km 区域、一个来源、一个图层，记录实际流量后再扩到
  15/25 km，禁止一次性下载全球包来“试试”。
- 恢复时由用户确认当月流量上限；未确认前只允许 `cache` 模式。

## 验收指标

- 数据完整性：每源下载字节数、校验结果、解析要素数和空间范围均非静默空值。
- 道路：主骨架召回、双端连续性恢复、悬空短枝数量、交叉口完整度和三档墨量。
- 水体：海/湖/江面覆盖召回、矢量边界一致性、灰色大水面残留和细线误判数量。
- 建筑：新增覆盖率、重复率、高度有效率和地标保留率。
- 构图：芝加哥网格、纽约海岸、米兰放射/环状结构需分别保住城市身份；不以
  单一总分取代人工审美复核。
- 打印：按喷嘴宽度和层高过滤后，道路/水体/建筑仍保持非零有效数量；正式
  3MF 经项目验证器达到 0 errors / 0 warnings。
