# B＋C 正式接入：平顶街块与局部地表微纹理

2026-09-08，用户批准采用 B＋C。实现状态：本机代码已接入；未部署，未跑
整城 3MF，未通过最终水体裁切／切片／实物验收。参考仍只作为设计线索，
不宣称取得作者原始算法。

## 启用范围与阶段边界

- 新任务使用 `--urban-organization C` 或 `block-first`，且场景策略为 active
  时，S5 保存 `ScenePolicy.z_texture`，参与策略指纹。
- 其他组织路线、audit 模式以及没有该政策的历史快照维持原状；不是所有
  历史生成脚本都自动改变。重复调用 S6 不允许替换已经冻结的 Z 方案。
- S6 最终道路切缝后，以实际完整块面支撑计算平顶；坡差较大则保留随地形
  原厚度。核心 BO 和地标的既有平顶高度不变。
- S6 在 VL/VO 来源绿地候选内，扣除城市块、地标、水体及道路保护带，冻结
  独立的 `surface_grounding.ground_texture` 表面计划。该对象不是植被实体。
- 原始 `TerrainSurfacePlan` 数组、指纹不变。纹理作为有来源边界的表面细节
  绑定它，不回写 S2/S3、也不把合成纹理当作 DEM。
- S7 GLB 与 S8 共用 `materialize_textured_terrain`：实体化已冻结微纹理，并
  与同一地形实体做 union。纹理不在 renderer 中重新随机计算。
- 为避免粗预览地形盖住微纹理，启用该方案时 GLB 地形使用正式地形网格；
  这可能增加整城 GLB 时间，不能用局部耗时推算整城性能。
- S8/S9 检查纹理表面指纹及实际地形 mesh 指纹，不允许丢失纹理后仍显示通过。

## 集中参数

来源：`aesthetic/z_texture.py::ZTexturePolicy`；实际值保存于 ScenePolicy、
S6 观测证据以及最终地形报告，管理员报告增加中文“平顶街块与局部地表微纹理”作用链。

| 参数 | 当前值 | 意义 |
| --- | ---: | --- |
| `max_block_relief_mm` | 0.24 mm | 完整块底高差不超过该值才抬平；不是全城统一海拔 |
| `amplitude_mm` | 0.07 mm | 地表合成增量上限 |
| `wavelength_mm` | 0.8 mm | 名义纹理横向尺度，具体波长混合为其 0.5–1.7 倍 |
| `boundary_fade_mm` | 0.15 mm | 到允许区边界平滑衰减；边界增量为零 |
| `road_half_clearance_mm` | 0.16 mm | 仅扩大纹理禁入范围，不改变原道路缝宽 |
| `overlap_mm` | 0.12 mm | 微纹理实体嵌入已有地形，避免悬浮贴片 |
| `max_edge_mm` | 0.10 mm | 局部微纹理三角形最大边长 |
| `seed` | 20260908 | 可复现的连续场；不是每个街块随机抬高 |
| `max_faces` | 2,000,000 | 单次纹理规划预算；超限明确报错，不能悄悄丢纹理 |

代码中的连续场已与 PNG 实验共用同一函数。实验 PNG 的像素边缘衰减改为
正式几何的精确边界距离，因此边界有小幅采样差别；不是把 PNG 高度栅格
直接转换成正式实体。

## 回归结果

巴黎真实约 1 km 局部，复用已存 R3 绿地窗口，保持原 25 km 模型比例：

- 5 个允许区域，38,656 个纹理表面三角形；允许面积 13.0337 mm²。
- 实测最高微起伏增量 0.06990 mm。
- 99 个裁剪城市块，B 高度沿用完整原块最高支撑，不由裁剪后支撑重新定高。
- 纹理地形 union 与街块分别闭合，纹理增加实体体积约 0.39355 mm³。
- 局部生成、网格检查、斜视图与诊断 3MF 导出共 4.06 秒（本机热缓存）。
- 本局部诊断**不包含地标和水体实体**，但纹理禁入区仍扣除了它们；不应当
  被当成完整巴黎作品或通过打印验收的成品。

产物：`output/paris_BC_real_mesh_20260908_v4/`，包含 `report.json`、
`A_actual_oblique.png`、`BC_actual_oblique.png` 和 `diagnostic_local_BC.3mf`。

自动回归覆盖：S5 启用范围、最低厚度、陡坡保护、边界接触孔洞、纹理禁入区、
无绿地不加噪声、冻结后篡改拒绝、S8 缺失纹理拒绝、GLB 与正式地形同网格。
本轮组合 97 项回归通过，已有 8 条 Pillow 弃用警告；不是模型验证器警告。

### 实际失败发现与修正

最初自适应细分后按坐标焊接，重新连接了真实巴黎绿地孔洞的独立边界扇区，
出现非流形边。改为每个已有连续贴地面片内的共享边中点细分，不重新焊接
同坐标不同身份的顶点，加入相接孔洞回归。另修正诊断裁剪地形的封底方法。
未放宽闭合、法向、正体积或指纹守卫。
