## 一、崩溃修复（v0.1 静默失败 → v0.2 真正工作）

v0.1 中建筑和 block_base **从未成功生成**（错误被 `try/except` 吞掉），输出仅 5MB（地形+道路+水）。v0.2 修复后输出 **72MB**（全要素）。

| Bug | 原因 | 修复 |
|-----|------|------|
| `'Polygon' object has no attribute 'make_valid'` | Shapely 2.0.7 的 `make_valid` 是模块级函数，不是方法 | 全部替换为 `shapely.make_valid(polygon)` |
| `No module named 'matplotlib'` | block_base 用 matplotlib 做点-多边形判断 | 改用 `shapely.contains()` |
| `fast_simplification` Python 3.9 崩溃 | Python wrapper 用了 `float \| None`（3.10+ 语法） | 新增 `_fast_simplify_direct()` 直接加载 C 扩展 `.so` |
| block_base 400 条非流形边 | 9033 个 block 拼接后共享边界顶点 | 拼接后追加 Manifold repair |

**受影响文件**：`_brick_transform.py`, `block_base.py`, `coords.py`, `water.py`, `osm.py`, `city_cache_loader.py`, `terrain.py`, `mesh_repair.py`

## 二、Kevin Lynch 4 类地标分类系统（全新功能）

v0.1 用 `is_tag_landmark() → bool` 做二元判定，所有地标统一处理（×1.4 高度，5m buffer）。

v0.2 引入 `LandmarkCategory` 四维分级，每类差异化参数：

| Category | 检测逻辑 | 高度倍率 | 2D 膨胀 | 排斥缓冲 | 上限 |
|----------|---------|:-------:|:------:|:-------:|:---:|
| **SPIRITUAL** (Cat 1) | `historic`/`religion`/教堂/寺庙 | **×1.8** | 5m | **12m** | 6.0mm |
| **URBAN_HUB** (Cat 2) | 体育场/车站/医院/大学/市政厅 | **×1.3** | **8m** | **15m** | 5.5mm |
| **GEOMETRIC** (Cat 3) | 高度 top 2% 或面积 top 5% | **×1.5** | 5m | 10m | 5.5mm |
| **SEMANTIC** (Cat 4) | name 匹配正则 + area ≥ 2500m² | **×1.5** | 5m | 8m | 5.5mm |

**西湖验证结果**（685 km²）：

| 指标 | v0.1 | v0.2 | 变化 |
|------|:----:|:----:|:----:|
| 地标数 (BL) | 288 | **420** | +46% |
| Landmarks mesh | 46,938 面 | **76,738 面** | +63% |
| 类别分布 | — | SPIRITUAL=6, URBAN_HUB=6, GEOMETRIC=541, SEMANTIC=11 | — |
| 3MF 大小 | 64 MB | **72 MB** | +13% |
| watertight | ✅ | **✅** | — |

**新增文件**：`_landmark.py`（+120 行）

**修改文件**：`config.py`（+LANDMARK_CATEGORY_PARAMS）, `_layer_preprocess.py`（分类逻辑+差异化减法）
