# 西溪湿地微起伏：实际切片验证

## 结论

低于层高的起伏仍可能改变实际挤出走线，但效果取决于表面相对切片层的位置。本次验证支持“保留微起伏并检查实际切片”，不支持“低于层高直接过滤”，也不证明实物一定美观。

## 输入和实验

- 输入来自参考杭州 3MF 的西溪湿地灰色地形表面，非凭空添加噪声。
- 来源测量见 `reference_green_surface_audit_20260906.md`。
- 表面 Z 为 1.212147–1.282331 mm，峰谷差约 0.070184 mm。
- 使用已有 0.1 mm 栅格采样构造封闭样片，实际 XY 10.9 × 6.9 mm。因此不是原三角网格的无损裁切。
- 四种基底高度偏移：0、0.03、0.06、0.09 mm。不改变微起伏幅度。
- 每种偏移各设一个同均高平面对照，共八块；基底均从 Z=0 起。
- Bambu Studio 02.08.02.60，X1 Carbon 0.4 mm 喷嘴，Generic PLA，0.12 mm Fine 官方预设解析后加载。
- 已从实际 G-code 核对：首层 0.20 mm、后续层高 0.12 mm、喷嘴 0.4 mm、无熨烫。
- 样片封闭、面朝向一致、体积为正；只离线切片，没有连接打印机或发送打印任务。

## 实际结果

|基底偏移|参考微起伏相对同均高平面对照|
|---|---|
|0.00 mm|Z=1.28 mm 层出现局部凹口轮廓，顶部走线不再是完整均匀平面。|
|0.03 mm|最后几层走线基本相同，未呈现明显起伏。|
|0.06 mm|最后几层走线基本相同，未呈现明显起伏。|
|0.09 mm|出现额外 Z=1.40 mm 局部岛状挤出路径，总长度约 46.20 mm；平面对照该层无挤出。|

这不是简单地让整个样片多一层：新增路径仅分布在局部。四个偏移是离散示例，不代表出现纹理的概率为 50%。

## 产物与复现

- 构造：`tools/verify_microrelief_slicing.py`。默认不覆盖已有输出。
- 解析：`tools/analyze_microrelief_gcode.py`。读取实际正向挤出路径，圆弧以最多约 0.02 mm 弧长步长离散用于绘图；不把空走或回抽画成纹理。
- 输出：`output/microrelief_slice_20260906/`。
- `manifest.json` 保存源采样文件指纹、八块样片坐标和高度。
- `slice_analysis.json` 保存 G-code 指纹、有效设置和分样片分层挤出长度。
- `actual_toolpaths.png` 为实际走线对照，显示走线中心，不是挤出宽度模拟或实物照片。
- `eight_coupons.stl` 为测试几何，`plate_1.gcode` 为 X1C 测试切片，不应未经设备核对直接用于其他打印机。

CLI 在该测试目录内执行：

```sh
/Applications/BambuStudio.app/Contents/MacOS/BambuStudio \
  --datadir /private/tmp/map-microrelief-bambu-20260906 \
  --load-settings 'machine.json;process.json' \
  --load-filaments filament.json \
  --arrange 0 --orient 0 --slice 0 eight_coupons.stl
```

纯切片命令退出码 0。附加 `--export-3mf` 的打包过程报无法打开临时文件，因此没有宣称导出了已验证的切片 3MF。上述结果以实际 G-code 为证据。

## 对生成策略的影响

1. 保留真实地形的细小起伏，不因其小于层高直接压平。
2. 是否添加风格化地表肌理应另设策略，不能由本次实验推断参考作者使用了随机噪声。
3. 可打印性检查需要同时观察幅度、横向尺度、层高和相位；不仅比较一个高度阈值。
4. 此次仅增加独立验证工具与报告，未修改生产 pipeline，未自动重新开启 vegetation。
5. 仍需实际打印小样评价触感、材质、光照和美感；当前验收状态为 `human_review`，非正式城市模型可打印性通过。
