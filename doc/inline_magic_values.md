## 可操作建议

1. **短期**：将"重复定义"表中的值提为 config.py 常量，实现文件改为 `from config import X`
2. **中期**：把 §7（z_displacement）和 §6（brick_transform）的视觉参数抽成 `style_presets.py` 或 JSON，方便 A/B 对比
3. **不动**：§5.1 GCJ-02 坐标系数（数学公式，无可调性），§12/§11 的多进程阈值（纯工程调优，与城市特征无关）
