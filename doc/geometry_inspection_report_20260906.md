# 几何完整性与接地检测报告

> 后续更新：普通道路贴地与有完整岸点的直桥支撑已加入逐项检测；
> 弯桥、缺岸点等未支持情形明确阻断。水体最终布尔接触与跨桥切片仍待验收。
> 详见[道路与桥岸接地记录](road_grounding_item3_20260906.md)。

新增独立检测族 `outcomes.geometry_inspection`，报告升级为 v3。
JSON 保留逐项证据，中文 HTML 单独展示检测表；不影响几何参数，不增加游客接口。

## 必须分开的三类信息

| 类别 | 内容 | 能说明什么 |
| --- | --- | --- |
| 造型测量 | 脚下最大坡差、屋顶相对旧质心方案的抬高量 | 显示造型风险，不能凭空设置审美合格阈值 |
| 本次几何检测 | S6 计划指纹、实际网格与冻结分片一致性、数量、闭合／绕向／正体积 | 仅证明当前冻结地形范围内的实现合同 |
| 最终验收 | 道路接触、桥岸衔接、水体布尔裁切后接触、切片细节存活 | 未实现／未运行必须显示待检测，不能继承单元测试的通过结论 |

状态：通过、失败、待检测、不适用、已测量（非验收）。
历史快照没有接地计划时显示待检测；没有地标时相应项不适用；
有计划却缺少网格、网格被修改或指纹不一致时显示失败。
闭合不是可打印的充分条件，S6 通过不是 S8 通过，S8 通过不是 S11 通过。

当前“整面接地”的强证据来自地形分片生成与实际网格摘要绑定，
不是重新对水体布尔裁切后的最终组合做全表面距离检测；报告明确这一范围。
未提供独立测量的距离值不会填 0 冒充实测结果。

## 执行和管理员联动

1. S7 报告：计划和造型测量已存在，实际网格项待检测。
2. S8：在进入下一道网格门禁前，保存带 run/attempt 名称的
   `pipeline_measurement_report_s8.<identity>.json/html`，不改写 S7 已冻结报告。
   S8 成功时登记为该 Stage 的产物；若 S8 自身异常，文件仍在本地，但未经
   ledger 认领不会扩大管理员产物查询权限。
3. S10 最终报告：重新使用实际网格构建检测项，最终组合和切片仍据实待检测。
4. 管理员 Context 获取最新报告时优先 S10 → S8 → S7；轮询仅返回检测摘要，
   完整证据仍在管理员报告里。带 identity 的 S8 报告不能在缺失任务归属时被猜测查出。

实现：`aesthetic/geometry_inspection.py`（只读检测），
`aesthetic/measurement_report.py`（报告），`webapp/pipeline_console.py`（管理员摘要）。
